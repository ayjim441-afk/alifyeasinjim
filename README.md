# 🏛️ Alif Yeasin Jim — Academic & Personal Portfolio

A sleek, responsive, and modern personal portfolio website built for **Alif Yeasin Jim**, an undergraduate student in **Islamic History & Culture** at **Abudhar Giffari College, Dhaka** (National University, Bangladesh).

Designed with a warm editorial amber aesthetic, modern bento-grid layouts, dark/light theme switching, and direct email delivery via Web3Forms API.

---

## ✨ Features & Highlights

- **🌓 Dynamic Dark & Light Modes:**
  - **Dark Mode:** Deep slate/navy canvas with amber glows and subtle borders.
  - **Light Mode:** High-contrast crisp paper aesthetic with strong dark shadows for bento cards.
  - One-click toggle with preference persistence in `localStorage`.

- **📱 100% Mobile Responsive:**
  - Tested across mobile devices (390px+ viewports) with zero horizontal overflow.
  - Floating top navigation bar with quick theme switcher.
  - Collapsible mobile hamburger navigation drawer.
  - Floating scroll-to-top button.

- **📬 Direct Gmail Contact Form (Web3Forms API):**
  - Integrated with Web3Forms (`Access Key: 96d77c17-6389-4e27-8649-1439b8300472`).
  - Messages sent from the contact form are delivered straight to **`ayjim441@gmail.com`**.
  - Includes real-time submission feedback, loading state, and native fallback.

- **🎯 Interactive Dynamic Tab Title:**
  - Browser tab title automatically updates as you scroll through sections (`Alif Yeasin Jim — About`, `Alif Yeasin Jim — Education`, `Alif Yeasin Jim — Research & Works`, etc.).

- **✨ Fluid Dual-Layer Mouse Cursor Follower:**
  - Custom glowing dot + smooth trailing ring that responds to cursor speed and interactive hovers.
  - Automatically disables on touch and mobile devices via `@media (hover: none), (pointer: coarse)`.

- **📚 Curated Academic & Research Showcases:**
  - **About Me:** Student profile, academic philosophy, and core interests.
  - **Education & Trajectory:** Illuminated vertical timeline detailing ongoing B.A. Honours studies and coursework.
  - **Competencies & Skills:** Categorized competencies (Historical Inquiry, Archival Study, Essay Writing, Historiographical Comparison).
  - **Featured Research:** Interactive cards with dedicated full-text modal viewer.
  - **Footer:** Photo avatar, auto-updating copyright year (`© <Year> Alif Yeasin Jim`), and quick social links (Instagram, Email, WhatsApp).

   ```bash

   ```

2. **Open the Project:**
   - Simply double-click `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).
   - *Or* run with VS Code **Live Server** extension:
     - Right-click `index.html` and select **"Open with Live Server"**.

## 🌐 Free Deployment Options

You can host this static portfolio for free in under 2 minutes:

### 1. GitHub Pages
1. Push this folder to a GitHub repository.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
4. Your site will be live at `https://<username>.github.io/<repo-name>/`.

### 2. Vercel / Netlify
1. Drag and drop the project folder directly onto [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on [Vercel](https://vercel.com).
2. Deploys instantly with a free SSL certificate.
